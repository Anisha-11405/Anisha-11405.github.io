SmartLabel AI

Full-stack label compliance screening application

SmartLabel AI checks the mandatory declarations on packaged-product labels. A user uploads a photo of a label, the application reads the text with OCR, extracts the declarations, and evaluates them against a set of preliminary compliance rules. Each result comes with the evidence found and a recommended action, so a reviewer can see why a label was scored the way it was.

What it does

  • Accepts a label image (up to 10 MB) with a live preview, and reads it with Tesseract OCR on the server. If OCR is not available, the user can paste the label text instead.
  • Extracts 15 declarations from the text with pattern matching: product and common name, manufacturer, packer, importer, country of origin, net quantity, MRP, batch or lot number, manufacturing and packing dates, best before, consumer care details, unit sale price and product dimensions.
  • Runs 11 explainable checks. Each check records its requirement, legal reference, the evidence found and the action to take, and returns Pass or Review.
  • Calculates a compliance score from the share of checks passed and assigns an overall status. Anything software cannot judge, such as legibility and prominence, is routed to manual verification rather than passed automatically.
  • Saves every inspection to MySQL with a readable ID such as SL-000123, so results can be reopened later.
  • Provides a dashboard with inspection totals by status and the average score, plus a history view with search, filter and delete.
  • Exports each inspection as a printable report or as JSON, includes a demo mode for trying it without a label, and has a responsive layout for mobile screens.

How an inspection runs

  1. Upload. The React client sends the label image, product category and package type to the API as multipart form data.
  2. OCR. The service passes the image to Tesseract and collects the recognised text.
  3. Extraction. Regular expressions pull each declaration out of the text.
  4. Rule evaluation. The 11 checks run against the extracted values and produce a score and status.
  5. Persistence. The inspection is stored through Spring Data JPA and the full report is returned to the client.
